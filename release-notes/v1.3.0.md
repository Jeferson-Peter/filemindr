## Highlights

- Added `undo` support for recorded move operations
- Added run history commands for inspection, retention, and cleanup
- Improved `explain --verbose` with applied templates and matched rule candidates

## Features

- `filemindr undo <run_id>` now reverts recorded `move` operations safely
- Run history commands:
  - `history list`
  - `history show <run_id>`
  - `history prune --days 7`
  - `history clear --yes`
- Dynamic file naming improvements with `stem_safe`
- Richer `explain` output for debugging and rule verification

## Quality Improvements

- History now focuses on real CLI runs instead of internal calls
- History listing is ordered by execution time and filters legacy noise by default
- Release notes are now versioned in the repository and consumed by the release workflow
- README updated with examples for explain, history, and undo

## Install

```bash
pip install -U filemindr
```

## Distribution

This release is published to PyPI. GitHub Release assets are not used as the distribution channel.
