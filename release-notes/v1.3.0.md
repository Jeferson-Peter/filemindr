## Highlights

- Added `undo` support for recorded move operations
- Added versioned release notes consumed automatically by the release workflow
- Refined run history to better support real CLI usage and recovery flows

## Features

- `filemindr undo <run_id>` now reverts recorded `move` operations safely
- Undo runs in reverse order using recorded run history
- GitHub Releases now read version-specific notes from `release-notes/`

## Notes

- `undo v1` only restores `move` operations
- `trash`, `overwrite`, and `copy` events are not restored automatically

## Install

```bash
pip install -U filemindr
```

## Distribution

This release is published to PyPI. GitHub Release assets are not used as the distribution channel.
