## Highlights

- Added template support for dynamic destination paths
- Added `rename_template` for dynamic output names
- Hardened watcher behavior, trash safety, and path resolution
- Automated publishing and GitHub Release flow

## Features

- Dynamic target path templates in `move_to` and `copy_to`
- Dynamic `rename_template` support
- Template placeholders such as `{stem}`, `{suffix}`, `{ext}`, `{yyyy}`, `{mm}`, and `{dd}`
- Improved release workflow for automated publishing from `development`

## Quality Improvements

- Standardized path resolution across commands
- Made trash behavior fail safely
- Improved watcher handling for unstable files
- Split move and copy reporting more clearly
- Improved CLI output compatibility across terminals

## Install

```bash
pip install -U filemindr
```

## Distribution

This release is published to PyPI. GitHub Release assets are not used as the distribution channel.
