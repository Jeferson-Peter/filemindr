## Highlights

- Added ignore patterns for `run`, `watch`, and `explain`
- Added JSON execution reports for `run`
- Continued improving recovery and automation workflows

## Features

- New `ignore` field in YAML config with glob-style patterns
- Ignore patterns now apply consistently in:
  - `run`
  - `watch`
  - `explain`
- New JSON report export:
  - `filemindr run -p home --report report.json`

## Notes

- Ignore patterns are matched using glob-style rules such as `*.tmp` and `~$*`
- JSON reports currently write to the path provided by `--report`

## Install

```bash
pip install -U filemindr
```

## Distribution

This release is published to PyPI. GitHub Release assets are not used as the distribution channel.
