## Highlights

- Added `stem_safe` for normalized file names in `rename_template`
- Improved `explain --verbose` with matched rule candidates, templates, and rendered names
- Added run history commands with retention and cleanup support

## Features

- Dynamic target path templates in `move_to` and `copy_to`
- Dynamic `rename_template` support
- New `stem_safe` placeholder for safer, normalized output names
- Run history commands:
  - `history list`
  - `history show <run_id>`
  - `history prune --days 7`
  - `history clear --yes`

## Quality Improvements

- Hardened watcher stability handling
- Made trash behavior fail safely
- Standardized path resolution across commands
- Improved summaries and explain output
- Refined release automation and GitHub Release generation

## Install

```bash
pip install -U filemindr
```

## Distribution

This release is published to PyPI. GitHub Release assets are not used as the distribution channel.
